# Weather Dashboard

## Project Overview

A real-time weather dashboard built using JavaScript Fetch API and asynchronous programming.

## Features

- Fetch API
- Async/Await
- REST API Integration
- JSON Parsing
- Error Handling
- Search by City
- Dynamic UI Updates

## Weather Information Displayed

- Temperature
- Humidity
- Wind Speed
- Weather Description

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API

## Concepts Demonstrated

- Asynchronous JavaScript
- API Calls
- Promise Handling
- Fetch API
- DOM Manipulation
- Error Handling

## Outcome

A dynamic weather dashboard that retrieves and displays real-time weather data based on user input.
